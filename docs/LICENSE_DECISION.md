# Lizenzentscheidung

**Stand: offen – bis zur Entscheidung gilt „Alle Rechte vorbehalten“.**

Die Wahl der Lizenz ist eine Produktentscheidung der Eigentümerin bzw. des Eigentümers und wurde daher bewusst nicht vorweggenommen. Eine restriktive Ausgangslage lässt sich später problemlos öffnen; eine einmal erteilte offene Lizenz lässt sich für bereits veröffentlichte Versionen nicht zurücknehmen.

## Optionen

| Lizenz | Geeignet, wenn … |
| --- | --- |
| **MIT** | maximale Verbreitung und Wiederverwendung gewünscht ist, auch in kommerziellen Produkten Dritter |
| **Apache-2.0** | wie MIT, zusätzlich mit ausdrücklicher Patentlizenz |
| **AGPL-3.0** | Weiterentwicklungen – auch als gehosteter Dienst – offen bleiben sollen |
| **Proprietär** | ein kommerzielles Produkt geplant ist und der Code nicht weitergegeben werden soll |

## Hinweise

- Alle verwendeten Abhängigkeiten stehen unter permissiven Lizenzen (MIT, Apache-2.0, ISC) und sind mit jeder der Optionen vereinbar.
- Farbpaletten und Texte sind eigene Inhalte des Projekts.
- Nach der Entscheidung: `LICENSE`-Datei anlegen, `license`-Feld in `package.json` setzen, README anpassen.
